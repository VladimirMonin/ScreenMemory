# ADR-011 — частный релиз: FTS5, встроенный SDK и агентская приёмка

- Статус: **принято владельцем 2026-10-02**, реализация продолжается.
- Источник решения: подтверждённая цель `muqhdldy-5nzeny` (S01–S08 до локального релиза).
- Baseline: `18a2608cad800d1b3cb783d586964784e267351d`.
- Change note: `CN-20261002-01`; уточняет исходный [master v3](../ScreenMemory_Full_Development_Plan_v3.md)
  и планы S01/S04/S06/S07/S08. Девять исходных планов и их SHA-256 остаются неизменными.

## Решение владельца

1. **SQLite FTS5 — да; embeddings и семантический поиск — нет.** `FTP5` в запросе
   трактуется как FTS5. Полноценный текстовый поиск использует подписи, описания,
   OCR и метаданные, точные совпадения, ранжирование и фильтры. Qwen embedding,
   sqlite-vec, query embeddings и vector generations не входят в этот релиз и не
   являются обязательными gates. Vision-описания и OCR остаются в scope.
2. **LM Studio SDK включается в приложение.** Published SDK и необходимый приватный
   runtime поставляются с приложением; отдельная установка SDK/dev Node пользователем
   не требуется. Bridge остаётся вне WebView, GUI/CLI/MCP используют один host.
   Сам LM Studio и веса — внешние локальные зависимости, не встроенный inference engine.
   Скачивание весов требует отдельного разрешения; сохранение и FTS5 работают без AI.
3. **Проверки выполняют агенты.** Parent оценивает визуал, сценарии и качество поиска
   по фактическим данным, screenshots и размеченному synthetic корпусу. «Ручной» case
   означает агентское взаимодействие с собственным тестовым окном, не поручение владельцу.
   Mock/статический анализ не заменяет live evidence.
4. **Работа — связными продуктовыми milestones.** Не дробить цель на бесконечные
   технические микросрезы. Локальная проблема останавливает только опасную операцию
   или неисправную lane; независимая полезная работа продолжается. NOT_RUN не равен PASS.
5. **Исполнение и review — native Pi / `openai-codex/gpt-6.1-sol`; oracle — native Pi /
   `openai-codex/gpt-6-astra`.** Parent принимает решения и коммитит, один writer на
   worktree, reviewer fresh/read-only. Старый маршрут DeepSeek → Sol6 и автоматическая
   смена provider/режима больше не применяются к этой цели.

## Применение к требованиям исходных планов

| Владельцы | Уточнение, а не заявление о готовности |
|---|---|
| S01 technical proofs | Embedding/vec proofs исключены. Обязательные FTS5, SDK, packaging проверки сохраняются у соответствующих S06/S04/S08; без исполнения не помечаются PASS. |
| S04 / RT, JOB | Vision runtime, профили, durable queue, Automatic/Manual/Off, pause/cancel/retry и TTL сохраняются; embedding instance/co-resident policy не требуется. |
| S05 / AI | OCR, строгие описания, категории, overrides и revision guards сохраняются. |
| S06 / IDX-01…05, JOB-03 | Лексический FTS5 вместо hybrid/vector. Проверки обновления индекса, фильтров, ранжирования, latency и отмены сохраняются; query не вызывает модель. |
| S07 / GUI, API, SEC | Общая прикладная логика FTS5, полноценные CLI/MCP и передача изображений с правами; нет семантических режимов. |
| S08 / OPS, DATA | Локальная сборка/установщик, backup/restore/purge, upgrade и isolated Windows acceptance сохраняются. |

Это не переводит старые NOT_RUN в PASS и не сокращает проверку сохранности. Перенос
технического proof к реализующему его этапу отражается в актуальном handoff; все
обязательные результаты должны быть проверены перед завершением всей цели.

## Неизменные границы

- Один host/writer библиотеки, freeze до UI, без второго capture после выбора.
- Saved только после проверенного canonical и commit; staging/канон не обычный кеш.
- WebP/AVIF, полный канон, immutable editing и независимость от AI остаются.
- Не трогать живую библиотеку, чужие процессы, clipboard и модели; тесты только
  на изолированных owned roots, синтетике и собственных окнах. Cleanup/migration
  по правилам владельца; никакого ослабления guards ради зелёной проверки.
- Push/публичный релиз и установка на личной рабочей системе требуют отдельного разрешения.
- Если недоступна обязательная финальная проверка, выполнить всё независимое и
  указать точный остаток; нельзя назвать такую сборку принятой Windows V1.

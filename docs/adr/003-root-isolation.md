# ADR-003 — Pre-host namespace and Windows root identity

Status: **implemented candidate S01-T02b, independent review pending**. Sources: master v3 §§4, 6; S01 §§2.4–2.5, 6.1, 7.3, T02/T05; [ADR-001](001-upstream-strategy.md), [ADR-002](002-foundation-protocol.md). This decision does not amend the nine source plans.

`sm-isolation` holds product/dev/test app IDs, window-class and endpoint prefixes, secret key namespaces and distinct existing `{data,config,cache,webview}` layouts. Installed paths come ONLY from a trusted explicit configuration with `ScreenMemory`, `ScreenMemory.Dev`, `ScreenMemory.Test` directory labels. Tests pass an explicit test root. There is no host startup, shell registration, IPC binding, secret read, install/update, WebView/CSP integration or donor composition root. T06 must integrate actual shell/profile/scopes; no unused tauri config is shipped.

Resolver rejects UNC/device/ADS, relative/traversal, non-fixed/non-NTFS and missing/inaccessible paths before accepting a root. The Win32 SDK FFI is local to `windows.rs` (SDK ABI linked to system kernel32; no new external binding dependency/version or network dependency fetch). `CreateFileW` checks each directory prefix with `FILE_FLAG_OPEN_REPARSE_POINT|FILE_FLAG_BACKUP_SEMANTICS`; volume/file identity from opened handles (not lowercase strings) rejects same/ancestor/descendant overlaps with explicitly supplied donor roots. Junction and symlink are rejected independently. All four handles remain owned by the result. No automatic adoption or cleanup; unknown donor root means failure. Root identifiers/path stay internal and typed diagnostic events omit them.

**Boundary:** Read-only *preparatory* root resolution is not an ownership lease, DB write authority, backup or migration. T05 must enforce handle-relative/swap-resistant path traversal across concurrent attacker mutation, acquire an OS-backed HostLease before any writer, implement migration preflight/backup/integrity and test races/crash. Current prefix checks are not an atomic guarantee against malicious concurrent renames/reparse swaps; until T05 no process startup/SQLite writer may rely on this candidate for write authorization. A forbidden root on a separate inaccessible drive fails closed rather than being silently skipped. Synthetic NTFS proof and remaining gates: [T02b evidence](../progress/S01/t02b-isolation.md).

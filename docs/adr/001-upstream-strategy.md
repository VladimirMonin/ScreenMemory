## Context and decision

Master v3 §4.5 / §6 and S01 §§2, 13 T01 demand reuse without making Inspector's clipboard product the foundation's composition root. Keep the original fixed SHA as separate clean detached reference, compare every imported change to it, and gradually extract only required Windows capture/context/UI pieces into ScreenMemory owners. **The new `shotd` must never import/call `inspector_rust_core::run()`**: that function initializes Inspector database/crypto/migrations, background services and plugin capabilities. `win/src-tauri/src/main.rs` is a shell reference, not a new host. Capture adaptation is S02; WebP/AVIF, SQLite-vec and LM Studio bridge remain later S01 technical probes/owners and are absent from the donor contract.

Before ordinary foundation runtime: new app/bundle identity, data/cache/config roots, WebView profile, SecretStore keys, Windows window/class/lock names and strict IPC/asset allowlist. Disable original updater/autostart, tracker, clipboard/audio/Bluetooth/network/sync/backup/retention tasks. Donor source may only be executed in clean synthetic Windows test VM/account after isolation or approved bounded baseline, never in personal environment. MIT license and copyright notice must follow substantial code; third-party font/model/media licenses require separate asset provenance review. **No model downloads or asset redistribution approved here.** Distinguish mechanical provenance-preserving move from behavioral adaptation with separate evidence/tests.

Current donor history is a separate fetched reference (`refs/remotes/upstream/plan-baseline`); preserving ancestry before importing code is a parent/integrator decision, not implied by this document. Do not rewrite the nine plans or merge donor wholesale. Alternatives rejected for now: (1) transplant entire donor and call `run()` (unsafe side effects and ownership); (2) full pre-Windows rewrite (loses early feasibility proof). This ADR records an implementation direction, not accepted Windows or legal compliance evidence.

## Consequences / next decision

Minimal T02 recommendation: in isolated clean Windows account, establish manifest-based MSVC/Node/pnpm/WebView2 facts and build original SHA without running app; record command/exit/lock changes. Separately create the minimum namespace-isolated shell/composition root (no Inspector `run`) before any ordinary smoke. Only then bounded menu baseline on synthetic desktop with native dropdown, Explorer context menu, browser select, optional mixed DPI; no model work. If build/download/network or donor license/asset provenance blocks, report exact blocker rather than upgrade/install by guess. S01-UP-02/S01-BLD-01/S01-CAP-01 remain T02, and stage gates remain open.

# S02 — первая галерея и ограниченный preview (candidate)

На основе `0676315` в кодовом коммите `a907312` реализован первый пользовательский срез: authenticated GUI session получает первые 24 committed records, React отображает список и открывает выбранный WebP из host asset ID. Первая страница без pagination/thumbnail; диагностика и capture сохраняются. При `Saved` или `ready` список обновляется, есть ручное обновление. После кодового коммита изолированный synthetic smoke открыл и штатно закрыл реальное окно: `GUI-WINDOW-START = PASS`; библиотека была пустой, поэтому **отображение WebP в WebView и сквозной capture→gallery→preview = NOT_RUN**. Без clipboard/editor/hotkey.

Preview принимает только lowercase canonical UUIDv4, host разрешает идентичность и наличие asset; ни path, ни свободная команда от WebView не принимаются. Legacy hex transfer проверяет размер <=8 MiB *до* конкатенации, а затем offset/next_offset, total_size, mime=image/webp, asset ID, EOF и SHA256 по всем частям. При превышении — `PREVIEW_TOO_LARGE`, повреждении — `PREVIEW_UNAVAILABLE`; React декодирует bounded hex, создаёт `blob:` URL, отзывает при смене/закрытии/unmount. CSP разрешает `blob:` только для `img-src`; boundary gate проверяет это. Отказ preview не затрагивает сохранённый канон. Остаточный риск: существующий host storage read полностью загружает canonical file при **каждом** чанке, прежде чем GUI узнает размер; устранение — отдельная host-owner задача, не проверено runtime.

Первоначально `--locked --offline` дал exit 101 из-за нового прямого `sha2` в crate lock metadata: lock обновлён только `cargo test --offline`, затем `--locked --offline` exit 0. Ранее полный GUI тест дал 9/10: устаревшее ожидание `gallery` в NOT_IMPLEMENTED исправлено, повтор полного GUI 14/14 exit 0. Первый parent contracts gate дал exit 1 из-за пропущенного `sha2` в GUI allowlist, а Clippy — exit 101 на двух синтаксических замечаниях в assembler; узкие исправления внесены, повторные parent gates exit 0. При ошибке обновления React теперь убирает устаревшие записи/preview, а новый выбор сбрасывает прежний spinner; list/preview ожидания ограничены timeout. Независимый scoped static re-review после правок — PASS для кода, не runtime. Скрипт preview-gui теперь не ожидает gallery/library_counts в unfinished и корректно принимает ручное закрытие окна. Selfcheck остановился **до создания нового test root**, потому что сборка не смогла заменить exe существующего ранее project-owned `shotd.exe` из другого тестового root; чужой live процесс не завершали. Отдельный isolated target обошёл блокировку **без остановки чужого host**: окно открылось на новом пустом test root и корректно закрылось, повторный self-check подключился к тому же host, собственный host остановлен. Оставшийся чужой PID проверен живым; новый owned host отсутствует. Это `WINDOW_START_PASS`, **не** `VISIBLE_WEBP_PASS`: синтетическая библиотека пуста, WebP в окне не показывали. Кодовый срез зафиксирован как `a907312`; live WebP и полная приёмка S02 остаются открытыми.

## Повторный прогон с синтетическим WebP (owner scope)

На отдельном project-owned UUIDv4 root штатный `StorageWorker` сохранил synthetic WebP 360×180 (64 байта), record/asset — UUIDv4, raw exit 0. Первый реальный `GuiSession::list` дал `PermissionDenied` и 0 записей (exit 1): `Profile::Owner` не выдавал уже требуемый host/session `Scope::ListRecords`. Публичный тест `Authenticator → authorize` до исправления падал (exit 101); в этой итерации право добавлено **только Owner**, `TestReadOnly` по-прежнему получает отказ. Повтор: credentials 6/6, Rust application+GUI suite и scoped Clippy exit 0; contracts `outcome=PASS`, `stage_result=IN_PROGRESS`.

После offline rebuild настоящий `GuiSession` через authenticated host получил ровно 1 запись и её `image/webp` (64 байта, `safe_code=None`, exit 0); assembler проверяет чанки и SHA. Поля `width/height` в ответе asset равны 0, потому что chunk wire не несёт геометрии: это **не** утверждение о размере декодированного WebP. Отдельный browser smoke собранного React с mock IPC и checked-in CSP подтвердил `blob:` изображение с intrinsic 360×180 (exit 0; private screenshot в `.pi/preview-artifacts/`). Реальное окно на **заполненном** test root открывалось и закрывалось, self-check/reopen и остановка своего host прошли (exit 0); старый чужой host не тронут. Подключение автоматического WebView2 debugger было недоступно (exit 1), а клик по карточке в живом окне не наблюдался: **VISIBLE_WEBP_IN_TAURI = NOT_RUN**, не PASS. Одноразовые исходники fixture/probe удалены из tracked tree; исходные планы не менялись.

# WORKFLOW — частное приложение до локального релиза

Источник: [ADR-011 / CN-20261002-01](../docs/adr/011-private-release-scope.md),
подтверждённая владельцем цель `muqhdldy-5nzeny`. Исходные девять планов сохраняются;
ADR уточняет их scope, не доказывает реализацию.

## Доска и завершение

Веди [docs/TASKS.md](../docs/TASKS.md) крупными milestones S01–S08: статус,
контракт готовности, исполнитель/owner, evidence, открытый риск и следующий шаг.
Не делай из документа список каждого trait/файла. Текущий Git/source и свежие
проверки важнее устаревшего candidate-отчёта. Закрывай задачу только по её контракту;
не объявляй code commit принятой стадией. Raw логи/screenshots/БД — в изолированных
ignored `.pi` outputs, краткое безопасное evidence — в `docs/progress/`.

Scope: FTS5 lexical/exact/filters, **без embeddings/семантики/sqlite-vec**. Vision/OCR
и revisions остаются. SDK LM Studio и приватный runtime входят в поставку, не в
WebView; SDK и dev Node не должны устанавливаться пользователем отдельно. Сам
LM Studio и веса — внешние зависимости, AI опционален для capture/library/FTS5.

## Исполнители

- Native Pi `sm-writer` и fresh/read-only `sm-reviewer`: `openai-codex/gpt-6.1-sol`.
- Oracle при реальном тупике/неопределённости: native Pi `oracle` на
  `openai-codex/gpt-6-astra`, консультация через parent/supervisor. Если после ответа
  осталась существенная развилка, продолжи тот же resumable oracle и прими решение.
- Один writer на cwd/worktree; parent синтезирует, исправляет после освобождения
  writer, выполняет независимые gates и коммитит. Не запускай writer swarm.
- Для многосоставного делегированного milestone — один top-level async workflow,
  дети внутри него, durable output bindings. Базовый локальный workflow:
  `.pi/orchestration/screenmemory.milestone.workflow.js`; модели передаются явно.
- До launch проверь capabilities/models и topology. Отдельные owners при независимых
  source boundaries, один writer при едином тесно связанном seam. Исполняемые тесты
  workflow локальны; `.pi` не считается production-кодом или релизным артефактом.
- Не заменяй маршрут внешним CLI, другим provider/model или foreground без разрешения.
  Старые DeepSeek/Sol6 fallback-настройки этой цели не применяются.

## Проверки выполняет агент

Сам открывай owned synthetic окна, взаимодействуй и оценивай физические screenshots,
preview, ошибки, DPI и основные действия. Проверяй принадлежность окна/процесса;
не отправляй ввод в чужое активное окно. При потере фокуса откажись от глобального
ввода и выбери безопасную альтернативу. Не проси владельца нажать кнопку вместо тебя.

Качество FTS5 оценивается на заранее размеченном корпусе RU/EN: слова/фразы/точные
коды/пустая выдача/фильтры, ожидаемые IDs и ранжирование; отдельно — изменения,
удаления, latency и отсутствие скрытых model calls. Parent изучает evidence,
независимый reviewer проверяет результат; один успешный query не вся приёмка.

## Блокер принадлежит конкретной операции

Обычный дефект/устаревший отчёт/локальный сбой не пауза всей цели: локализуй,
исправь либо используй безопасную альтернативу, продолжай независимое полезное.
Не повторяй подготовку и unrelated audits без изменившегося риска. При тупике —
Astra oracle, не бесконечное дробление и не поручение ручного теста пользователю.

При lane infrastructure failure останови неисправную lane, сохрани exact run/status,
repo/cwd/ref и partial diff либо clean proof; повторяй только тем же Pi-протоколом.
Не запускай конкурирующего writer до подтверждения освобождения cwd. Для утраченного
разрешения, секрета или объективно недоступного обязательного стенда сообщи точный
остаток, выполняя всё остальное; NOT_RUN/BLOCKED не PASS и не обход сохранности.

Приёмка цели: финальная регрессия, isolated backup/restore/upgrade, Windows
installer/staging без dev tools, evidence и SHA. Публичная публикация/push, личная
библиотека, чужие модели/процессы и скрытые downloads не разрешены этой целью.
